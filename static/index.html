DISK IMAGE NAMING ANALYSIS

Uses only filenames already stored in the SQLite index. Analysis is read-only and optional. Ambiguous sets can be approved individually or in confirmed batches; nothing is saved automatically, and files are never renamed, mounted or modified.

SIDFLOW SIMILARITY DATA

Powered by SIDFlow (Chris Gleissner)
Checking local similarity data…
Downloads the pinned SIDFlow 0.8.0 full export as a 194 MB compressed file, verifies both compressed and decompressed SHA-256 digests, imports its weighted 58-dimensional neighbour graph, then removes the temporary 982 MB source. Allow about 1.8 GiB free during the update; the existing working database is preserved unless promotion succeeds.

BUILD INDEX FROM LOCAL USB
